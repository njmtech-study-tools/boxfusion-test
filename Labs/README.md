## 🎯 How to Use These Labs

1. **Study the Theory & Code**: Open each topic folder to review the original assessment screenshot, verbatim code sample, and step-by-step breakdown.
2. **Execute Interactive Re-Testing**: Navigate to `../retest` and run `npm start` to test your knowledge against the exact assessment questions in real-time.
3. **Verify Code Behavior**: Run the provided runnable test scripts using `node` or `jest` to inspect DOM mutations and execution logs.
